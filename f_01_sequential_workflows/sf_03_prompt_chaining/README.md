## Summary
Implements the Prompt Chaining sub-workflow for sequential graph execution.


## 📌 Overview
Short example module for Prompt Chaining.

## 📂 File-by-File Explanation
- `__init__.py`: Marks this directory as a Python package for imports.
- `blog_state.py`: Defines the workflow state structure passed between nodes.
- `evaluation.py`: Evaluates generated content quality and completeness.
- `generate_blog.py`: Generates the blog draft from the produced outline.
- `generate_outline.py`: Generates a structured outline before full content generation.
- `main.ipynb`: Notebook walkthrough for interactive experimentation.
- `main.py`: Primary entry script to run this workflow example.
- `model.py`: Configures and initializes the model used in this workflow.
