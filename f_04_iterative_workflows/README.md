# 4️⃣ Iterative Workflows

## 🎯 Concept
This module introduces loop-based graph execution, where generation and evaluation are repeated until quality conditions are satisfied.

## 🧠 What You Learn
- How to design generator-evaluator-optimizer loops.
- How to stop iteration using quality checks.
- How to maintain evolving state across multiple passes.
- How iterative refinement improves LLM outputs.

## 🧩 Subfolders
### 🔹 sf_08_llm_based_tweet_generator
Iterative tweet generation pipeline with evaluator and optimizer feedback loops.

## 🚀 Suggested Learning Path
1. Trace one full generation cycle.
2. Observe evaluator-driven re-tries.
3. Tune stopping conditions for balance between quality and cost.
