# 👤 SF 20: Human In The Loop (Simple)

## 📌 Overview

This folder contains a minimal human-in-the-loop chatbot flow showing how user interaction and graph state can be coordinated.

## 📂 Files

### 🧠 Core Components

- `main.py`: Script entry point.
- `chat_node.py`: Chat node logic.
- `chat_state.py`: Conversation state schema.
- `model.py`: Model setup and call logic.

### 🧪 Notebook

- `main.ipynb`: Interactive version for testing the same flow.

## ▶️ How To Run

### Run Python script

```bash
python main.py
```

### Run notebook

Open `main.ipynb` in VS Code and execute cells.
