# 🛠️ SF 21: Human In The Loop (Advanced With Tools)

## 📌 Overview

This folder demonstrates an advanced human-in-the-loop chatbot with explicit tool usage and richer state handling.

## 📂 Files

### 🧠 Core Components

- `main.py`: Script entry point.
- `chat_node.py`: Chat node implementation.
- `chat_state.py`: Chat state schema.
- `model.py`: Model initialization and invocation.

### 🔧 Tools

- `tools_defined.py`: Tool definitions used in the workflow.

## ▶️ How To Run

```bash
python main.py
```
