# 5️⃣ Chatbot Workflows

## 🎯 Concept
This module introduces conversational graphs with message state management and model invocation for multi-turn chatbot behavior.

## 🧠 What You Learn
- How to represent chat history in graph state.
- How chatbot nodes process user messages and return assistant replies.
- How to structure a minimal but extensible chat workflow.

## 🧩 Subfolders
### 🔹 sf_09_simple_chatbot
Foundational chatbot with state schema, chat node, and model wiring.

## 🚀 Suggested Learning Path
1. Understand chat state updates per turn.
2. Extend response logic with tools, memory, or retrieval in later modules.
