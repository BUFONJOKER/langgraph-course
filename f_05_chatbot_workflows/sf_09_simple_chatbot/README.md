# 🧪 SF_09_SIMPLE_CHATBOT: Simple Chatbot

## Summary
Implements the Simple Chatbot chatbot sub-workflow for conversation flow.


## 📌 Overview
Short example module for Simple Chatbot.

## 📂 File-by-File Explanation
- `__init__.py`: Marks this directory as a Python package for imports.
- `chat.py`: Implements chat handling logic for message flow.
- `chat_state_schema.py`: Defines the workflow state structure passed between nodes.
- `main.ipynb`: Notebook walkthrough for interactive experimentation.
- `main.py`: Primary entry script to run this workflow example.
- `model.py`: Configures and initializes the model used in this workflow.
