# 🧩 SF 22: Simple Subgraph

## 📌 Overview

This folder shows a basic LangGraph subgraph example, useful for understanding graph composition and modular workflow design.

## 📂 Files

### 🧠 Core Files

- `main.py`: Script example for simple subgraph usage.
- `main.ipynb`: Notebook variant for interactive exploration.

## ▶️ How To Run

### Run Python script

```bash
python main.py
```

### Run notebook

Open `main.ipynb` in VS Code and execute cells.
