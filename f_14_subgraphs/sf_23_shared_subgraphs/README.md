# 🔗 SF 23: Shared Subgraphs

## 📌 Overview

This folder demonstrates how multiple flows can reuse or share subgraph logic to reduce duplication and improve maintainability.

## 📂 Files

### 🧠 Core Files

- `main.py`: Shared subgraph example script.
- `main.ipynb`: Interactive notebook version.

## ▶️ How To Run

### Run Python script

```bash
python main.py
```

### Run notebook

Open `main.ipynb` in VS Code and execute cells.
