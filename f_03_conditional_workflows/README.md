# 3️⃣ Conditional Workflows

## 🎯 Concept
This module focuses on branching logic in LangGraph. Routing decisions are made from state values, so the graph can choose different paths dynamically.

## 🧠 What You Learn
- How to implement conditional edges in workflows.
- How to route execution by computed values or LLM classification.
- How to keep branch-specific logic modular and testable.
- How to design robust state schemas for conditional execution.

## 🧩 Subfolders
### 🔹 sf_06_simple_workflow
Quadratic equation workflow that routes to distinct, repeated, or complex root handlers.

### 🔹 sf_07_llm_based_workflow
LLM-based sentiment/diagnosis style routing with positive and negative response branches.

## 🚀 Suggested Learning Path
1. Build intuition with sf_06 mathematical branching.
2. Apply the same routing model to LLM outputs in sf_07.
