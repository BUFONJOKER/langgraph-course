# 🧪 SF_06_SIMPLE_WORKFLOW: Simple Workflow

## Summary
Implements the Simple Workflow sub-workflow for conditional routing behavior.


## 📌 Overview
Short example module for Simple Workflow.

## 📂 File-by-File Explanation
- `__init__.py`: Marks this directory as a Python package for imports.
- `calculate_discriminant.py`: Computes quadratic discriminant to drive conditional routing.
- `calculate_roots.py`: Coordinator for root computation based on discriminant branch.
- `complex_roots.py`: Handles computation branch for complex roots.
- `distinct_roots.py`: Handles computation branch for two distinct real roots.
- `main.ipynb`: Notebook walkthrough for interactive experimentation.
- `main.py`: Primary entry script to run this workflow example.
- `repeated_root.py`: Handles computation branch for repeated real root.
- `show_equation.py`: Formats/displays the quadratic equation being solved.
- `state_schema.py`: Defines the workflow state structure passed between nodes.
