# 7️⃣ Streaming

## 🎯 Concept
This module combines chatbot workflows with streaming output so users receive incremental tokens/events instead of waiting for a full response.

## 🧠 What You Learn
- How to stream model outputs from a LangGraph workflow.
- How streaming works with state and memory saver patterns.
- How to improve UX for long-form responses.

## 🧩 Subfolders
### 🔹 sf_11_chatbot_with_streaming_memory_saver
Streaming chatbot implementation integrated with memory saver.

## 🚀 Suggested Learning Path
1. Run chat once with normal response.
2. Compare with streaming behavior for responsiveness.
