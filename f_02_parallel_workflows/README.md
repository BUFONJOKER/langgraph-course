# 2️⃣ Parallel Workflows

## 🎯 Concept
This module demonstrates fan-out and fan-in patterns in LangGraph, where multiple independent branches run in parallel and their outputs are merged into a single final result.

## 🧠 What You Learn
- How to run independent computations concurrently.
- How to structure state for branch-safe updates.
- How to aggregate multiple branch outputs into one summary.
- How to use parallelism for both deterministic and LLM-based tasks.

## 🧩 Subfolders
### 🔹 sf_04_simple_workflow
Parallel cricket metric calculations (strike rate, boundary stats, summary).

### 🔹 sf_05_llm_based
Parallel LLM essay analysis dimensions, then combined overall feedback.

## 🚀 Suggested Learning Path
1. Start with sf_04 for pure logic parallel nodes.
2. Continue with sf_05 for parallel LLM evaluators and merged feedback.
