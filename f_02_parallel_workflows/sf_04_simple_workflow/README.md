# 🧪 SF_04_SIMPLE_WORKFLOW: Simple Workflow

## Summary
Implements the Simple Workflow sub-workflow for parallel branch processing.


## 📌 Overview
Short example module for Simple Workflow.

## 📂 File-by-File Explanation
- `__init__.py`: Marks this directory as a Python package for imports.
- `batsmen_state.py`: Defines the workflow state structure passed between nodes.
- `calculate_balls_per_boundary.py`: Calculates average balls faced per boundary hit.
- `calculate_boundary_percent.py`: Computes percentage of runs scored via boundaries.
- `calculate_strike_rate.py`: Calculates strike rate from runs and balls faced.
- `calculate_summary.py`: Aggregates computed batting metrics into a final summary.
- `main.ipynb`: Notebook walkthrough for interactive experimentation.
- `main.py`: Primary entry script to run this workflow example.
