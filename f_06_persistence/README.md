# 6️⃣ Persistence

## 🎯 Concept
This module explains checkpointing and memory persistence in LangGraph so workflows can preserve context and continue across interactions.

## 🧠 What You Learn

- How memory saver patterns retain conversational or intermediate state.
- How persisted state supports resumable and consistent behavior.
